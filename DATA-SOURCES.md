| **efinance/qstock/adata** | 类似东财封装                                                               | 各有维护节奏    | 与本项目手写的东财接口重叠度高      |

> 此前决策（见 CHANGELOG 2026-09-09）：baostock/SQLite 换源需 Python sidecar，暂不引入；
> 东财彻底封禁或强制注册时再重启。该结论仍然成立——**除非**需要 AKShare/Baostock 独有的
> 数据（分钟线、历史成分），届时 sidecar 作为独立进程按需启用（`python sidecar.py` 子进程 + JSON over stdout）。

## Tushare Pro（HTTP API · Node 原生可接 · 积分制）

**重要澄清**：此前「TS 生态无官方客户端」指的是 Python 免费库；Tushare Pro 本身是
HTTP API（POST JSON + token），**无需 sidecar**，本项目已内置适配器
（`server/src/quant/tushareAdapter.ts`，`TUSHARE_TOKEN` 环境变量启用）。

能补的三个结构性缺口（研究有效性问题）：

| 接口                               | 能补什么                                                 | 对应缺口             |
| ---------------------------------- | -------------------------------------------------------- | -------------------- |
| `stock_basic`（list_status=D/P/L） | **含退市/暂停上市股的完整证券表**                        | 幸存者偏差           |
| `index_weight`                     | **指数历史成分快照**（按月）                             | 历史宇宙/回测宇宙    |
| `income` / `fina_indicator`        | **双日期 PIT 财务**（ann_date 公告日 + end_date 报告期） | PIT 口径的年报级因子 |

**状态（2026-09-12）：token 已配置（server/.env，gitignored），适配器实测接入**：

- `stock_basic` **可用**：实测 L=5562 只（含行业/上市日）；退市股（D）与暂停上市（P）
  名单同接口可得。**免费积分频控实测仅 1 次/小时**（错误码 40203）——适配器已带
  `*Cached` 包装（24h 磁盘缓存 + 上游失败回落陈旧缓存 + 并发去重），请求路径禁止直连。
  已接线：`/api/quant/health` 的 `tushare` 块（配置态 + 上市/退市/暂停计数）、
  截面响应的幸存者偏差声明（附退市股名单规模）。
- `index_weight` **免费积分无权限**（40203「没有接口访问权限」，非频控）——历史成分
  缺口需充值积分（约 2000+）或改用免费 Baostock（Python sidecar，见上节）。
- `income` / `fina_indicator`（双日期 PIT 财务）未实测，预计同样有积分门槛。

成本与注意：积分制（低积分接口覆盖窄且频控严，5000 积分以上基本无感；高校师生可
申请免费积分）；**数据协议限制再分发**——拉取数据只用于本机研究。未配置 token 时
适配器全部优雅跳过，免费东财通道不受任何影响。

## 决策建议

1. **短期**（零成本）：按缺口逐个实测东财 datacenter 报表名并接入（现成模式：
   `eventProvider` + 量化缓存 + 优雅降级），优先分析师一致预期（补齐 PEAD 的「预期」半边）。
2. **中期**（注册 token，零费用起步）：配置 `TUSHARE_TOKEN` 启用适配器，用
   `stock_basic(D)` + `index_weight` 修宇宙口径；`income` 双日期做年报级 PIT 校验。
3. **长期/实盘化**：再评估付费源与 sidecar（分钟线需求出现时）。
